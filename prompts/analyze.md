## 任务
对下面这条内容，从两个相互独立的维度打分，并给出结构化的判断。

### 维度一：相关度 relevance（0-10）
「这条内容讲的领域，和读者的方向有多相关」——只看主题，不看质量。

| 分数 | 含义 |
|---|---|
| 9-10 | 正中靶心：LLM 应用架构、Agent 工具调用、上下文工程、评测方法、多模态应用落地、AI 工程岗位与机会 |
| 7-8 | 高度相关：AI 工程实践、新工具/新框架、模型能力边界、行业结构性变化 |
| 4-6 | 沾边：泛技术话题、产品发布、行业新闻、AI 边缘应用 |
| 1-3 | 弱相关：与 AI 无关的科技新闻、消费电子、生活方式 |
| 0 | 完全无关：娱乐、美食、招聘广告、与读者目标无任何交集 |

### 维度二：可行动性 actionability（0-10）
「读者读完能不能做点什么」——只看可执行程度，不看主题。

| 分数 | 含义 |
|---|---|
| 9-10 | 今天就能动手：能立刻装上试、能改自己的代码、能马上投递的机会 |
| 7-8 | 本周能用上：可以借鉴一个具体做法或决策 |
| 4-6 | 将来可能用：值得知道，但暂时无从下手 |
| 1-3 | 纯资讯：读完只能"哦"一声 |
| 0 | 无法行动：观点、八卦、营销 |

## 校准示例（请对齐，不要自己另立标准）

| 内容 | relevance | actionability |
|---|---|---|
| 一篇讲「如何给 LLM 输出做 JSON Schema 校验」的工程博客 | 8 | 8 |
| 某厂商发布新一代模型，只有参数和榜单 | 6 | 3 |
| HN 热帖：某 AI 编码工具把用户邮箱泄露给网站 | 7 | 4 |
| 科技周刊，含工具推荐、资源、行业观察 | 5 | 4 |
| 某公司完成 B 轮融资 | 3 | 0 |
| 新款 MacBook Pro 评测 | 0 | 0 |

## 重要原则
1. **两个维度互相独立。** 一篇讲 AI 的文章可能相关度 9 但可行动性 2（纯观点）；一篇招聘信息可能相关度 5 但可行动性 9。
2. **来源本身是信号。** 来自一线从业者、官方文档、开源项目的深度内容，即使正文信息少，relevant 也不应低于 6。不要把「我不确定」打成 0 分。
3. **不要用世界级研究者的标准要求一个本科生。** 对他「能看懂、能上手、能写进简历」的东西就是高分。
4. 只有标题和很短摘要时，按来源与标题给出的信息判断，给中间分（4-6），不要惩罚性打低分。
5. 一天 20 条里，relevance ≥7 的通常有 2-5 条。如果你打出的 ≥7 少于 1 条，或超过 10 条，请复核自己的标准。
6. 营销稿、纯通稿、付费墙截断的残页，relevance 给 0，并在 reason 说明。
